## 🌟 Обзор проекта

**CleanGuard** — это десктопная утилита с открытым исходным кодом для обслуживания и оптимизации Windows, разработанная со строгими гарантиями безопасности корпоративного уровня. В отличие от традиционных клинеров, которые вслепую удаляют файлы и ставят под угрозу стабильность системы, CleanGuard следует принципу **«Безопасность на уровне архитектуры» (Safety-by-Architecture)**: каждый объект очистки проходит криптографическую проверку, ограничение доступа по системным границам и сверку с политиками безопасности до выполнения каких-либо действий.

В состав утилиты входят **14 специализированных модулей**, обеспечивающих комплексное освобождение дискового пространства, поиск дубликатов, безопасную очистку реестра с автоматическим бэкапом и откатом, управление автозагрузкой, удаление предустановленного мусора (bloatware) и телеметрии, ускорение сетевого отклика, мониторинг аппаратного обеспечения в реальном времени и автоматическое фоновое обслуживание.

## 🛡️ Архитектура безопасности

CleanGuard исключает любые случайные повреждения системы благодаря встроенным защитным барьерам:

1. **Модуль изоляции границ PathGuard**:
   - Жестко блокирует доступ к каталогам `C:\Windows`, `System32`, `SysWOW64`, `WinSxS`, `Boot`, `Program Files` и защищенным томам.
   - Полностью защищает персональные папки пользователя: `Рабочий стол`, `Документы`, `Изображения`, `Видео`, `Музыка`, `Загрузки`.
   - Канонизирует каждый путь (`GetFinalPathNameByHandleW`), блокируя обход каталогов через симлинки, junction points и жесткие ссылки.
2. **Защита от состояния гонки TOCTOU (Time-of-Check to Time-of-Use)**:
   - Повторная верификация дескрипторов и разрешений непосредственно перед удалением файла. В случае любых несоответствий операция прерывается.
3. **Автоматическое резервное копирование и откат**:
   - **Точка восстановления Windows (VSS Restore Point)**: Создание официальной контрольной точки системы перед масштабными операциями.
   - **Откат реестра**: Автоматический экспорт очищаемых ключей в датированный файл `.reg` с возможностью мгновенного восстановления в один клик.
4. **3-уровневая модель оценки рисков**:
   - 🟢 `БЕЗОПАСНО (SAFE)`: Кэши приложений, временные файлы и эскизы старше 24 часов.
   - 🟡 `ТРЕБУЕТ ВНИМАНИЯ (REVIEW)`: Системные журналы, дампы сбоев и кэши браузеров (требуют явного выбора пользователя).
   - 🔴 `ЗАБЛОКИРОВАНО (BLOCKED)`: Критические компоненты Windows и активные системные процессы (модификация категорически запрещена).

## 🚀 14 Основных модулей CleanGuard

```text
Комплекс CleanGuard
├── 📊 01. Панель управления      ── Текущее состояние системы, индикаторы дисков и быстрые действия
├── 🧹 02. Глубокая очистка       ── Многопоточный сканер системного и прикладного мусора
├── 🔍 03. Поиск дубликатов       ── Двухэтапный криптографический поиск (MD5/SHA256)
├── 🛡️ 04. Очистка реестра        ── Безопасный сканер с автобэкапом и откатом в 1 клик
├── 📦 05. Деинсталлятор программ ── Удаление Win32/UWP с очисткой остаточных файлов и хвостов
├── 🚀 06. Менеджер автозагрузки  ── Анализ и управление Run, Startup и Task Scheduler
├── ⚡ 07. Turbo RAM Бустер       ── Сброс кэшей Standby и очистка Working Set памяти
├── 🌐 08. Оптимизация сети       ── Сброс DNS, Winsock, настройка TCP и бенчмарк DNS-серверов
├── 🛠️ 09. Твики и приватность    ── Удаление Bloatware, отключение телеметрии и игровой режим
├── 💻 10. Монитор оборудования   ── Диагностика CPU, GPU, RAM, дисков, материнской платы и OS
├── ⏰ 11. Планировщик Auto-Care  ── Интеграция с Windows Task Scheduler для фоновой очистки
├── 🔄 12. Точки восстановления   ── Интеграция с Volume Shadow Copy (VSS)
├── 📜 13. Аудит и история        ── Логирование в SQLite WAL и экспорт отчетов в CSV/JSON
└── 🎨 14. Fluent интерфейс       ── Современная темная тема и мгновенное переключение 3 языков
```

### 1. 📊 Панель управления (Dashboard)
- Индикаторы заполненности всех локальных дисков (C:, D: и др.) с цветовым предупреждением о критическом остатке места.
- Общий индекс здоровья системы, нагрузка на оперативную память и кнопки мгновенного запуска сканирования.

### 2. 🧹 Модуль глубокой очистки (Deep Clean)
- Параллельное сканирование основных категорий накопившегося мусора:
  - **Временные файлы пользователя и ОС**: `%TEMP%`, `C:\Windows\Temp`.
  - **Кэши приложений и шейдеров**: DirectX Shader Cache, D3DSCache, Delivery Optimization.
  - **Эскизы Проводника**: Кэш миниатюр `thumbcache_*.db` и иконок.
  - **Дампы сбоев и отчеты об ошибках**: `MEMORY.DMP`, минидампы, логи WER и CBS.
  - **Изолированная очистка веб-браузеров**: Кэши Chrome, Edge, Firefox, Brave, Opera без затрагивания паролей, сессий и cookie.
  - **Корзина Windows**: Анализ объема удаленных файлов по каждому диску отдельно.

### 3. 🔍 Поиск дубликатов файлов (Duplicate Finder)
- Высокоскоростной двухэтапный анализ:
  1. Сравнение размеров файлов и контрольного хэша первых 4 КБ.
  2. Полное криптографическое хэширование по алгоритмам MD5 и SHA256.
- Наглядная группировка одинаковых файлов и умное автовыделение (оставить самый старый или самый новый).
- PathGuard исключает случайное удаление системных или установленных файлов.

### 4. 🛡️ Безопасная очистка реестра (Registry Cleaner)
- Диагностика устаревших и некорректных записей:
  - Недействительные идентификаторы CLSID и компоненты COM/ActiveX
  - Нарушенные файловые ассоциации и отсутствующие расширения
  - Ссылки на удаленные общие библиотеки DLL
  - Неверные записи деинсталляторов в реестре
- **Гарантия сохранности**: Автоматический бэкап в файл `.reg` перед любым изменением и восстановление в один клик.

### 5. 📦 Деинсталлятор программ и очистка остатков (Uninstaller)
- Отображение классических программ (Win32) и современных приложений Windows (UWP).
- Поддержка стандартного и тихого (silent) режимов деинсталляции.
- **Поиск «хвостов»**: Глубокое сканирование каталогов `%AppData%`, `%LocalAppData%`, `Program Files` и системного реестра для удаления мусора, оставленного после деинсталляции.

### 6. 🚀 Менеджер автозагрузки (Startup Manager)
- Полная ревизия веток реестра HKCU/HKLM `Run`, `RunOnce`, папок «Автозагрузка» и задач Task Scheduler.
- Анализ влияния каждого элемента на время загрузки системы (Высокое, Среднее, Низкое).
- Включение, отключение и настройка отложенного старта.

### 7. ⚡ Turbo RAM Бустер (Оптимизация памяти)
- Прямой вызов Win32 API `EmptyWorkingSet`.
- Сброс неиспользуемых резервных списков памяти (Standby list) без закрытия запущенных приложений и риска потери данных.

### 8. 🌐 Оптимизация сети и пинга (Network Booster)
- **Очистка кэша DNS** (`ipconfig /flushdns`): Устранение задержек резолвинга и ошибок маршрутизации.
- **Сброс каталога Winsock** (`netsh winsock reset`): Восстановление сетевых стеков.
- **Автоматическая настройка TCP/IP**: Оптимизация сетевых пакетов для снижения задержек в онлайн-играх.
- **Тестирование DNS в реальном времени**: Измерение времени отклика (ms) до серверов Cloudflare `1.1.1.1`, Google `8.8.8.8` и OpenDNS `208.67.222.222`.

### 9. 🛠️ Твики Windows и конфиденциальность (Tweaks & Privacy)
- **Удаление предустановленного софта (Bloatware)**: Безопасное удаление ненужных UWP-приложений (Cortana, Bing News, Xbox, Пасьянсы и др.).
- **Отключение телеметрии**: Блокировка служб отслеживания Microsoft DiagTrack и Connected User Experiences.
- **Очистка меню Пуск**: Отключение интернет-поиска Bing и рекламы в меню «Пуск».
- **Игровые оптимизации**: Настройка планировщика GPU и профилей энергосбережения.

### 10. 💻 Мониторинг оборудования (Hardware Monitor)
- Телеметрия всех ключевых узлов ПК в реальном времени:
  - **Процессор (CPU)**: Архитектура, количество физических и логических ядер, процент загрузки.
  - **Оперативная память (RAM)**: Общий, занятый и свободный объем, график использования.
  - **Видеокарта (GPU)**: Модель адаптера, версия видеодрайвера, объем видеопамяти.
  - **Накопители**: Модели дисков, интерфейсы подключения, типы (SSD, NVMe, HDD), свободное и общее пространство.
  - **Материнская плата и BIOS**: Производитель платы, модель и версия прошивки BIOS.
  - **Операционная система**: Редакция Windows, номер сборки (напр., 22631) и разрядность.

### 11. ⏰ Автоматическое обслуживание (Auto-Care)
- Интеграция с планировщиком задач Windows (`schtasks.exe`).
- Настройка регулярного запуска (ежедневно, еженедельно или во время простоя ПК).
- Поддержка тихого безголового режима (`--auto-clean`) без вызова графического окна.

### 12. 🔄 Точки восстановления системы (System Restore Point)
- Прямое взаимодействие с теневыми копиями томов Windows (VSS) через `SRSetRestorePointW`.
- Автоматическое создание точки отката перед потенциально рискованными действиями.

### 13. 📜 Аудит и журнал истории
- Фиксация всех выполненных очисток в локальной базе данных SQLite с поддержкой режима **WAL (Write-Ahead Logging)**.
- Учет освобожденного места за все время и количества удаленных файлов.
- Экспорт детальных отчетов в форматах **CSV** и **JSON**.

### 14. 🎨 Fluent-интерфейс и мультиязычность
- Элегантный темный дизайн в стиле Windows Fluent Design.
- Адаптивная верстка, масштабирование под High-DPI экраны.
- Мгновенное переключение языка интерфейса без перезапуска программы:

## 💻 Установка и запуск

### Системные требования
- **Операционная система**: Windows 7 SP1, Windows 8, Windows 8.1, Windows 10 или Windows 11 (32-bit / 64-bit)
- **Python**: Версия 3.8 или выше
- **Права доступа**: Для полноценной очистки системных каталогов и реестра рекомендуется запуск с правами Администратора.

### 1. Клонирование и настройка окружения

```powershell
# Клонирование репозитория
git clone https://github.com/Valijon21/cleaner_win.git
cd cleaner_win

# Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\activate

# Установка необходимых зависимостей
pip install -r requirements.txt
```

### 2. Запуск приложения

```powershell
# Запуск полнофункционального графического интерфейса (GUI)
python -m cleanguard.app.main
```

### 3. Автоматический тихий режим (Headless Auto-Clean)

Для запуска CleanGuard в фоновом режиме по расписанию (без вызова графического окна):

```powershell
# Очистка только безопасных компонентов (категория SAFE)
python -m cleanguard.app.main --auto-clean
```
